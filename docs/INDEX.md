# TripDiary docs(目次)

このフォルダの Markdown が仕様の正本です。

| ファイル | 内容 |
|---|---|
| 00_要件定義書.md | 目的・スコープ・機能要件・非機能要件・データモデル・制約・決定事項と未決事項 |
| 01_機能一覧.md | 機能 ID・優先度・状態・関連画面の一覧 |
| 20_設計書.md | プロジェクト構成・技術方針(バックエンド・フロント・認証・API・セキュリティ)・CI/CD・テストの方針 |
| 21_画面設計.md | 画面一覧・URL・画面遷移・画面ごとの要素・実装の状況 |
| 22_インフラ設計.md | AWS・Terraform・デプロイの設計(構成図・費用・段階的な構築)と、**実機での確認の記録**(改訂履歴) |
| 23_運用手順書.md | AWS の環境を、作る・動作確認する・消す手順(所要時間の実測、確認項目、片付けの確認、つまずきやすい点) |
| api/openapi.json | API 仕様書(OpenAPI)。コードから自動生成する(`backend` で `npm run openapi`)。手で編集しない |

## 命名規則
- `00_` 要件定義、`01_` 機能一覧
- `1x_` 機能群別の機能定義書(今後追加)
- `2x_` 設計・インフラ・運用
