# TripDiary docs

このフォルダの Markdown が仕様の正本です。

| ファイル | 内容 |
|---|---|
| 00_要件定義書.md | 目的・スコープ・機能要件・非機能要件・データモデル・制約・未決事項 |
| 01_機能一覧.md | 機能 ID・優先度・状態・関連画面の一覧 |
| 20_設計書.md | プロジェクト構成・技術方針・CI/CD |
| 21_画面設計.md | 画面一覧・URL・画面遷移・画面ごとの要素・モック方針 |
| api/openapi.json | API 仕様書(OpenAPI)。コードから自動生成する(`backend` で `npm run openapi`)。手で編集しない |

## 命名規則
- `00_` 要件定義、`01_` 機能一覧
- `1x_` 機能群別の機能定義書(今後追加)
- `2x_` 設計・インフラ・運用
